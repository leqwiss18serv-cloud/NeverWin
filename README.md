# NeverWin 🎮

Мобильная игра на **виртуальной валюте NC (NeverCoins)**. Никаких настоящих
денег — только внутриигровая валюта. Новый игрок получает **5000 NC** на старте.

## Возможности (v0.1.1)

- **Игры** — 4 мини-игры на NC с серверной логикой результата:
  - 🎲 «Больше — Меньше» (мин. 1000 NC, выигрыш x2, ничья — возврат);
  - ⚫ «Чёрное или Белое» (мин. 1500 NC, угаданный цвет x2, зелёный x5, шанс < 8%);
  - 🎯 «Кости: Чёт / Нечет» (мин. 500 NC, x2);
  - 🪙 «Орёл или Решка» (мин. 500 NC, x2, доступна в дуэлях).
- **Банк** — счета с названием, PIN из 4 цифр и ID из 6 цифр; пополнение,
  вывод на баланс, переводы по ID с уведомлениями; промокоды с гибкими лимитами.
- **Лидерборд** — ТОП-10 по сумме баланса и всех счетов.
- **Друзья** — заявки по нику, принятие/отклонение, мессенджер (текст, фото,
  эмодзи, realtime), удаление из друзей, **дуэли** с одинаковой ставкой.
- **Настройки** — тема, уведомления, подключение Supabase, выход.
- **Админ-панель** (только для администраторов): баны, выдача/списание NC,
  глобальные сообщения `ADMIN: ник / текст`, глобальный множитель x2,
  настройка игровых параметров без пересборки APK.

## Серверная часть

Вся денежная логика выполняется серверно (Supabase RPC в `supabase/schema.sql`):
ставки, вероятности, выплаты, переводы, дуэли, промокоды — атомарно, с защитой
от race condition. Параметры (мин. ставки, множители, вероятности, лимиты,
блокировки, админы, global x2) настраиваются через SQL без обновления приложения.
Без настроенного Supabase приложение работает в локальном режиме с теми же
правилами. Подробности разработки — в `WORK.md`.
